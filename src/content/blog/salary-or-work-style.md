転職を考えているけれど、年収を上げたいのか、働き方を変えたいのか、自分でもはっきりしない。求人を見ると、年収が高いものは忙しそうに見えるし、働きやすそうなものは年収が下がりそうにも見える。そんなふうに、条件の優先順位が曖昧なまま止まっている人もいます。

この記事は、どちらを優先すべきかを決めるものではありません。**転職で年収を上げたい気持ちと、働き方を変えたい気持ちを分けて、求人ごとに何を確認すれば比べられるのか**を整理します。

## 「年収」と「働き方」を、確認できる形にする

「年収を上げたい」「働き方を変えたい」は、どちらも人によって意味が変わる言葉です。そのままだと比べにくいので、確認できる問いに分けてみます。

**年収**
- 生活に必要な金額は、毎月の手取りでどのくらいか。求人条件を比べるときは、額面年収や月給、賞与・手当などの内訳と分けて確認する
- 上げたい理由は何か（生活の安心、将来の備え、納得感など）
- いまの年収で、足りないものは何か

**働き方**
- 時間: 残業は月にどのくらいまでなら続けられるか。休日に仕事の連絡が来ることは許容できるか
- 場所: 出社する日数、通勤にかかる時間、勤務地の範囲
- 裁量: 仕事の進め方や時間の使い方を、どこまで自分で決めたいか
- 安定性: 雇用形態、契約の更新の有無、給与のうち固定の部分と変動する部分

答えが出ない項目は、空欄のままで構いません。空欄になったところが、次に確認することです。

## 交換条件として見る

年収、時間、場所、裁量、安定性は、互いに関わり合うことがあります。ただし、どの条件がどう連動するかは、会社や職種によって違います。「年収が高い求人は忙しい」「働きやすい求人は年収が下がる」と決めつけず、求人ごとに事実を確認して比べます。

比べるときは、次のような表を使うと整理しやすくなります。

| 項目 | いまの状況と自分の希望 | 候補先で確認すること |
| --- | --- | --- |
| 収入（生活側は手取り／求人側は額面・内訳） | | |
| 時間（残業・休日） | | |
| 場所（出社・通勤） | | |
| 裁量 | | |
| 安定性 | | |

「候補先で確認すること」の欄には、求人票に書かれていることと、書かれておらず面接などで確認する必要があることを分けて書きます。たとえば、年収が示されていても、その額がどんな条件（賞与、手当、残業代の扱いなど）を含むのかは、求人票だけでは分からない場合があります。分からない部分は、「未確認」と書いて残しておいて構いません。

## 求人票だけでは分からないことを、確認する問いにする

候補が見つかったら、書かれていないことを「聞ける形の問い」にしておきます。答えが得られる場面は、応募前の問い合わせ、面接、内定後の条件確認などです。どの場面で聞けるかは会社によって違うため、聞く機会があれば、という前提で用意しておけば十分です。

- **年収:** 提示されている額は年収・月給のどちらか。賞与や各種手当、固定残業代などは含まれているか。固定部分と変動部分を分けるとどうなるか。昇給や評価の仕組みは、どのように説明されているか
- **時間:** 募集している部署について、残業時間や休日の連絡の運用はどのように説明されているか
- **場所:** 出社日数や勤務地は、どのようなルールで決まり、変更や異動の条件はどう定められているか
- **裁量:** 入社後の担当範囲や、意思決定に関われる場面は、どのように説明されているか
- **安定性:** 雇用形態と契約期間、更新の条件は、どのように定められているか

回答が得られなかった項目や、説明があいまいだった項目は、「未確認」のまま残しておきます。確認できなかったこと自体が、比べるときの情報になります。

## 優先順位は、暫定で決める

希望条件をすべて同じ重さで扱うと比べにくいため、最初は二つほどを「これは外せない」として選び、ほかは求人を見ながら見直す、という進め方が目安になります。

迷うときは、それぞれの条件について「許容できる範囲」を数字で置いてみます。

- 収入は、生活上どこを下限にしたいか
- 残業時間は、月にどこまでなら許容できるか
- 出社日数や通勤時間は、どこまでなら続けられそうか
- 固定給と賞与・手当などの変動部分を、どの程度まで分けて考えるか

未来を予想して決めるのではなく、「この範囲なら候補に残す」「ここを超えたら確認する」という線を暫定で置いておくと、求人ごとに同じ基準で比べやすくなります。

## 分かっていること、まだ分からないこと、自分の気持ち

書き出すときは、次の三つを分けておきます。

- **確認できている事実:** 今の手取り、残業の時間、勤務の日数など
- **まだ分からないこと:** 候補先の賞与や手当の条件、残業の実態、制度の運用など
- **自分の気持ち:** 「年収が上がると安心できる」「時間に余裕がほしい」など

気持ちの部分は、正しい・間違いで評価する必要はありません。
