転職するか迷う。残る理由も、辞めたい理由も、それぞれ書き出してみた。それでも、どちらが良いのか決められない。そんなとき、「自分は決断力がないのでは」と感じてしまう人もいます。

ただ、メリットとデメリットを並べても決まらないのは、並べ方の問題であることがあります。何と何を、どの物差しで比べるのかが決まっていないと、項目を増やしても比較しにくいままです。

この記事は、残ることも転職することも勧めません。まず「何を軸に比べるか」を分けて、決める前に確認したいことと、小さな一歩を渡すための記事です。

## 「残るか転職か」の裏で、動いている問い

「残る」か「転職する」かの二択に見えても、その裏には別々の問いが混ざっていることがあります。

- 嫌なのは、いまの仕事の内容か、いまの会社か
- 何かを手に入れたいのか、何かから離れたいのか
- 今すぐ決める必要があるのか、時間をかけていいのか
- 「転職」以外に、状況を変える方法はないのか

たとえば、仕事そのものは嫌いではないのに会社に違和感がある場合、動く先は「別の会社で同じ仕事」かもしれません。仕事と会社を切り分けて考えたい人は、こちらも参考になります。

## 判断軸を6つに分けて見る

給与だけで比べると、見落とすものが出やすくなります。ここでは6つの軸を挙げます。すべて満たす必要はなく、自分にとって重い軸を見つけるための材料です。

**給与・待遇。** 金額そのものより、「何のために必要なのか」を考えると軸が見えやすくなります。生活の安心なのか、将来の貯蓄なのか、納得感なのかで、必要な額も、代わりになるものも変わります。年収と働き方のどちらを優先したいのかが曖昧な人は、先に次の記事で整理しておくと進めやすくなります。

**成長。** いまの仕事で、学べることや任される範囲が広がっているか。逆に、同じことの繰り返しで止まっている感覚があるか。成長の感じ方は人によって違い、「新しいスキルが身につくこと」を指す人もいれば、「任される責任が増えること」を指す人もいます。自分にとっての成長が何を指すのかを、一度言葉にしてみると、比べやすくなります。

**健康。** 睡眠、気力、休みの取りやすさなど。疲れが強い状態では、「会社を変えたい」と「まず休みたい」が重なっていることがあります。眠れない、食欲がないといった体調面のつらさが続くなら、転職の判断より先に、医療機関などに相談することも選択肢です。

**裁量。** 仕事の進め方や、時間の使い方を自分で決められる範囲。責任の重さと引き換えに、裁量が大きくなることもあります。「自由に決められること」を求めているのか、「決められた枠の中で安定して働くこと」を求めているのかでも、合う環境は変わります。

**外での選択肢（市場価値）。** 「自分はいくらで評価されるか」と一つの数字で考えるより、同じ経験を求める求人があるか、他社でも使えるスキルがあるか、どんな役割が候補になるかを見ていきます。確かめる方法としては、求人を眺めて条件を知る、第三者に話してみる、などがあります。求人を見始める前に整理しておきたいことは、次の記事にまとめられています。

[転職サイトを見る前に整理しておきたい5つのこと](/jp/work/before-looking-at-job-sites)

**可逆性。** 選んだあと、やり直せるか。戻れるか。残る場合も、転職する場合も、「もしうまくいかなかったら」を一度考えておくと、決断の重さが変わることがあります。ここでは結果を予想するのではなく、「やり直しの選択肢が自分にあるか」を確認するくらいで十分です。

6つのうち、特に「これは手放したくない」と感じるものを、二つまで選んでみてください。

## 書き出して、軸ごとに比べる

軸が見えたら、簡単な表にして比べます。次のような形で構いません。

| 軸 | 今の会社に残る | 転職する |
| --- | --- | --- |
| 給与・待遇 | | |
| 成長 | | |
| 健康 | | |
| 裁量 | | |
| 外での選択肢 | | |
| 可逆性 | | |

点数をつけて合計する必要はありません。見たいのは、「自分が重いと感じた二つの軸で、どちらが自分に合いそうか」です。空欄になるところは、まだ情報が足りないという合図でもあります。

書き込むときは、事実と気持ちを分けておくと、あとで見返しやすくなります。たとえば「残業が月に何時間ある」は事実、「このままだと続けられない気がする」は気持ちです。どちらも判断の材料になりますが、混ぜて書くと、何が根拠なのか分からなくなります。また、転職先については、応募前には確認できないこともあります。分からない部分は無理に予想で埋めず、「未確認」と書いておけば十分です。

## 「残る」「辞める」以外の選択肢

二択にとらわれると、間の選択肢が見えにくくなります。

- **社内で変えられる余地を探す。** 担当、働く時間、上司との関係など。変えられるかどうかは職場によって違うため、まず確認できることを探します。相談する相手や伝え方に迷う場合は、先に自分の希望を「変えたいこと」と「変わらなくてよいこと」に分けて書いておくと、伝える内容を整理しやすくなります。
- **期限を決めて様子を見る。** 「1か月は今の会社で軸を確かめる」など、期限つきで保留にする。
- **情報だけ集める。** 求人や相談で外の情報を得ても、転職を決めたことにはなりません。
- **話してみる。** 頭の中だけで比べていて堂々巡りになっているなら、第三者に話すことで整理しやすくなることがあります。

## 今すぐ決めなくていいこと、確認しておきたいこと

**決めなくていいこと**
- 退職の時期
- 応募先
- 転職するか残るかの最終結論

**確認しておきたいこと**
- 不満の中心は、仕事か、会社か、疲れか
- 重い軸は何か（二つまで）
- 外部の事情で決まっている期限はあるか

## 次の小さな一歩

1. 6つの軸のうち、手放したくないものを二つ選んで書く
2. 上の表を、二つの軸だけ埋めてみる
3. 空欄になったところを、「調べる」「聞く」のどちらで埋めるか決める

一人で埋めにくいときは、第三者と整理する方法もあります。公的な無料相談を含め、キャリア相談の全体像は次の記事で確認できます。
